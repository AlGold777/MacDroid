# Кроссплатформенный файловый менеджер (Mac ↔ Android)
## Пользовательское описание (Product Spec), версия 3 — расширенная

Приоритеты по каждому пункту: **Must Have** (ядро первой версии), **Сильная** (после ядра), **Приемлемая** (по возможности), **Слабая** (риск/сложность выше пользы, но не исключается совсем).

---

## 1. Общая концепция

Двухпанельный файловый менеджер в стиле **Total Commander** для MacBook, управляющий файлами как на самом Mac, так и удалённо — на Android-телефоне (Xiaomi 14 Ultra), подключённом по Wi-Fi, с USB и Bluetooth как резервными каналами.

Каждая панель независима: пользователь сам решает, что показывать слева и справа (Mac-папка, папка телефона, в перспективе — другой источник). Возможные комбинации: Mac↔Mac, Телефон↔Телефон, Mac↔Телефон.

---

## 2. Модель панели (расширенная)

Каждая панель хранит и восстанавливает между сессиями:

```
Panel {
  source: "mac" | "phone"
  currentPath: string
  sortBy: "name" | "dateCreated" | "dateModified" | "size" | "type"
  sortDirection: "asc" | "desc"
  viewMode: "list" | "grid"
  showHidden: boolean            // Must Have — независимо для каждой панели
  filterQuery: string            // текущий быстрый фильтр
  navigationHistory: [...]       // история переходов назад/вперёд — Must Have
  scrollPosition: number
  columnWidths / thumbnailSize   // Сильная — вид панели запоминается отдельно
  tabs: [Panel, Panel, ...]      // Сильная — вкладки внутри панели
  selection: [...]               // не сохраняется между сессиями
}
```

Одна команда меняет местами полное состояние левой и правой панели целиком — источник, путь, сортировку, вид и выделение (**Сильная**).

---

## 3. Базовые файловые операции

- **Перемещение (Move)** — отдельная от копирования операция для одного или нескольких файлов/папок. Между Mac и телефоном выполняется как «копирование → проверка результата → удаление оригинала»; оригинал не удаляется до подтверждённого завершения копии. *Must Have.*
- **Оптимизация Move внутри одного источника** — использовать rename/move без повторной передачи содержимого там, где это возможно; иначе — безопасная схема копирование+удаление. *Must Have.*
- **Переименование** — через контекстное меню, inline-редактирование, горячую клавишу; симметрично на Mac и телефоне. *Must Have.*
- **Создание папки** в текущем каталоге активной панели с проверкой имени и конфликтов. *Must Have.*
- **Полноценная работа с папками** — копирование дерева, перемещение, переименование, рекурсивное удаление; при удалении папки — явное предупреждение, что удаляется всё содержимое. *Must Have.*

---

## 4. Управление панелями и навигация

- **Drag & Drop** — между панелями; из Finder/рабочего стола в любую панель; из панели Mac в другие приложения; из панели телефона на Mac. До отпускания — визуальная индикация «копирование» или «перемещение». *Must Have.*
- **Обмен панелей местами** — см. модель панели выше. *Сильная.*
- **Вкладки внутри панели** — несколько вкладок с независимыми источниками/путями/настройками на панель, по образцу Total Commander. *Сильная.*
- **Работа с путём** — кликабельные breadcrumbs, ручной ввод пути, переход к корню, копирование текущего пути, вставка пути для перехода. *Must Have.*

---

## 5. Быстрый доступ и поиск

- **Избранное и недавние папки** — отдельно для каждого источника; предустановленные каталоги: Downloads, Documents, Desktop, DCIM/Camera, Screenshots, Pictures. *Must Have.*
- **Запоминание пар источник→назначение** (например, `Phone/DCIM → Mac/Pictures/Xiaomi Backup`) — предлагать последнее использованное назначение. *Сильная.*
- **Повтор последней передачи** с теми же источником/назначением/правилами конфликтов, с повторной проверкой существования исходных файлов перед запуском. *Приемлемая.*
- **Быстрый фильтр текущей папки** — по части имени/расширению/маске (`*.jpg`), результат меняется по мере ввода без повторного сетевого листинга. *Must Have.*
- **Рекурсивный поиск по дереву папок** — отдельно от локального фильтра; для телефона — ограничение области/глубины, отмена, постепенный вывод результатов. *Сильная.*

---

## 6. Отображение файлов

- **Естественная сортировка** — папки выше файлов; `IMG_2` раньше `IMG_10`; дата съёмки изображения (если есть в метаданных) — отдельное поле сортировки, не подменяющее `mtime`. *Must Have.*
- **Скрытые файлы** — независимая настройка показа для каждой панели; на Android системный мусор скрыт по умолчанию, но доступен по желанию. *Must Have.*
- **Настройка вида панели** — размер миниатюр, ширина колонок, показ расширений — отдельно для каждой панели. *Сильная.*
- **Виртуализация больших каталогов** — порционная загрузка, виртуализированный список, индикатор загрузки, отмена листинга; папка на тысячи файлов не блокирует интерфейс. *Must Have.*

---

## 7. Управление мышью и клавиатурой

- **Полный набор горячих клавиш** в стиле Total Commander/macOS: `Tab` — смена активной панели, `Enter` — открыть, `Space/F3` — просмотр, `F5` — копировать, `F6` — переместить, `F7` — новая папка, `F8` — удалить, плюс переименование, инверсия выделения, переход вверх, ввод пути. *Must Have.*
- **Настраиваемые горячие клавиши** — переопределение сочетаний, восстановление стандартных профилей Total Commander/macOS. *Сильная.*
- **Контекстное меню** (правый клик) — открыть, просмотреть, копировать, переместить, переименовать, удалить, информация, копировать путь; для локальных объектов — «Показать в Finder». *Must Have.*
- **Работа с путями через буфер обмена** — раздельные команды: скопировать файл / скопировать имя / скопировать абсолютный путь / скопировать относительный путь / вставить путь для перехода. `Cmd+C` не должен неоднозначно означать одновременно «копировать файл» и «копировать путь». *Сильная.*

### Множественное выделение (из предыдущей версии, сохраняется без изменений)
- Cmd+клик, Shift+клик (диапазон), Cmd+A (всё), выделение рамкой, инверсия выделения; статус-бар панели показывает количество и суммарный размер выделенного.

## 8. Очередь и выполнение операций

- **Очередь файловых операций** — несколько копирований/перемещений формируют управляемую очередь, не блокирующую панели; можно менять порядок, приостанавливать, возобновлять, отменять отдельные задачи. *Must Have.*
- **Детальный прогресс** — текущий файл, общий прогресс, переданный объём, скорость, оценка оставшегося времени; корректный учёт папок и множества файлов. *Must Have.*
- **Автоматическое восстановление передачи** при кратком обрыве соединения, с ограничением числа попыток и статусом «ожидание подключения». *Must Have.*
- **Докачка больших файлов** с подтверждённого смещения после обрыва, с проверкой неизменности исходного файла перед продолжением. *Must Have.*
- **Временные файлы и атомарное завершение** — объект пишется под именем `.part`, финальное имя присваивается только после успешной проверки; повреждённый файл никогда не выглядит готовым. *Must Have.*
- **Предварительная проверка операции** — доступность источника/назначения, права доступа, свободное место, конфликт имён, попытка скопировать папку в саму себя, допустимость имени на целевой ФС. *Must Have.*
- **Изоляция ошибок отдельных файлов** — ошибка одного объекта не прерывает всю массовую операцию; проблемные файлы попадают в отдельный список. *Must Have.*
- **Итоговый отчёт операции** — количество скопированных/пропущенных/ошибочных объектов, общий объём, длительность, ссылка на журнал, команда «открыть папку назначения». *Must Have.*
- **Безопасная отмена** — при отмене недописанный временный файл удаляется либо явно остаётся для продолжения; видно, что уже обработано, а что нет. *Must Have.*
- **Системное уведомление о завершении** — после длительной фоновой передачи, с действием «Открыть папку». *Сильная.*

---

## 9. Конфликты и целостность

- **Расширенный диалог конфликтов** — помимо «Заменить/Пропустить/Переименовать»: заменять только более новые, пропускать идентичные, автоматически добавлять номер к имени, применить правило ко всем оставшимся; перед применением — сравнение размера и дат обоих объектов. *Must Have.*
- **Проверка целостности передачи** — контрольная сумма после передачи для крупных/критичных файлов, по настройке или порогу размера (не всегда, чтобы не создавать лишнюю нагрузку). *Сильная.*

---

## 10. Сравнение и пакетная обработка

- **Сравнение двух папок** — подсветка объектов, существующих только слева, только справа, либо совпадающих по имени, но отличающихся размером/датой; сравнение никогда не меняет файлы автоматически. *Сильная.*
- **Копирование различий после сравнения** — выборочная передача отсутствующих/изменённых файлов в выбранном направлении. *Приемлемая.*
- **Массовое переименование** — предпросмотр результата, шаблон, счётчик, дата, замена текста, изменение регистра; после базового переименования, во второй очереди. *Сильная.*
- **Удаление «лишних» файлов при синхронизации** — признано слишком опасным для первой версии. Если реализуется — только с предварительным планом, отдельным явным подтверждением и никогда не включённым по умолчанию. *Слабая — не входит в первую версию.*

---

## 11. Обновление и офлайн-режим

- **Ручное и автоматическое обновление панели** — команда Refresh плюс автообновление после локальных операций; изменения вне приложения обнаруживаются при возврате фокуса или через наблюдение за файловой системой, если источник это поддерживает. *Must Have.*
- **Безопасное поведение офлайн-панели** — при потере связи с телефоном показывается последнее закэшированное состояние с меткой времени; копирование/удаление/переименование/перемещение блокируются до переподключения; после восстановления связи каталог перечитывается. *Must Have.*

---

## 12. Просмотр файлов и изображений

- **Quick Look и открытие во внешнем приложении** — для локальных файлов используется системный Quick Look macOS; для удалённых файлов сначала создаётся временная локальная копия, затем открывается встроенный или системный просмотрщик. *Must Have.*
- **Предзагрузка соседних изображений** — при просмотре фото с телефона заранее подгружается ограниченное количество соседних файлов, чтобы листание не сопровождалось задержкой. *Сильная.*
- **Управляемый кэш миниатюр и изображений** — лимит объёма, политика вытеснения старых данных, ручная очистка; интерфейс показывает, что изображение ещё загружается с телефона. *Must Have.*

Остальные элементы просмотрщика (полноэкранный режим, зум, поворот, листание, удаление/копирование прямо из просмотрщика) — без изменений из предыдущей версии.

---

## 13. Подключение и Android

- **Ручное подключение как резерв mDNS** — если автообнаружение не сработало, телефон показывает адрес и порт для ручного ввода на Mac; после успешного сопряжения устройство запоминается. *Must Have.*
- **Расширенный статус телефона** — канал подключения, состояние файлового сервиса, активная передача, свободное место, заряд батареи; IP-адрес — в подробностях, не в основном статус-баре. *Сильная.*
- **Защита активной передачи от HyperOS** — во время передачи Android-приложение держит foreground service и ограниченный по времени wake lock; онбординг проверяет доступные настройки автозапуска/батареи и ведёт пользователя в нужные системные разделы MIUI/HyperOS. *Must Have.*
- **Проводное подключение по USB** — резервный транспорт для больших передач и сетей, где устройства не видят друг друга по Wi-Fi; ценнее, чем Bluetooth, реализуется после стабильного Wi-Fi-канала. *Сильная.*
- **Heartbeat как защита от выгрузки приложения** — отклонено в этом виде: сетевой heartbeat полезен только для обнаружения разрыва соединения, но сам по себе не предотвращает выгрузку процесса системой Android/HyperOS. Проблему решают foreground service, wake lock во время передачи и настройки батареи (см. выше). *Отклонено.*

---

## 14. Свободное место и удаление

- **Свободное место на каждой панели** — отображение свободного и общего объёма хранилища; перед записью — отдельная проверка с учётом места, уже зарезервированного другими задачами в очереди. *Must Have.*
- **Информативное подтверждение удаления** — количество файлов/папок, суммарный размер, способ удаления; для телефона — явное указание безвозвратности, для Mac — выбор между Корзиной и окончательным удалением. *Must Have.*

---

## 15. Технические уточнения протокола (исправления к предыдущим версиям)

- **Формулировка защищённого канала.** Убрать формулировку «TLS поверх SFTP» — она технически некорректна. Корректно: **SFTP через SSH с проверкой ключа сопряжённого устройства** (аутентификация по публичному ключу, зафиксированному при первом сопряжении). Альтернативный вариант — собственный протокол поверх TLS, но эти две схемы не следует смешивать в одном описании. *Must Have.*
- **Модель дат файлов.** SFTP не гарантирует наличие даты создания файла. Обязательное поле для сортировки и отображения — дата изменения (`mtime`). Дата создания и дата съёмки (EXIF) показываются и участвуют в сортировке только там, где источник действительно их предоставляет, и никогда не подменяют `mtime` по умолчанию. *Must Have.*

---

## 16. Вне рамок первой версии

- Полный доступ к внутренним данным сторонних Android-приложений (недостижимо без root).
- Системная «Корзина» на телефоне (Android не предоставляет такой механизм для сторонних приложений).
- Редактирование файлов «на месте» — только просмотр изображений, без редакторов текста/видео/аудио.
- Синхронизация в реальном времени с отслеживанием изменений (это файловый менеджер по запросу, а не облачная синхронизация).
- Автоматическое удаление «лишних» файлов при односторонней/двусторонней синхронизации (см. п. 10) — не включается по умолчанию, если вообще реализуется.
- Heartbeat как самостоятельное средство защиты от выгрузки Android-приложения системой (см. п. 13) — заменяется на foreground service + wake lock + настройку батареи.
