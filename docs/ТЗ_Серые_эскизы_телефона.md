# ТЗ: серые эскизы фото телефона в режиме «Сетка»

## 1. Проблема
В режиме сетки для файлов телефона вместо эскизов фото остаются серые плитки. В версии 2.1.24 исправлена одна причина (обрезанный кадр из префикса), но симптом сохраняется. Точная причина **не установлена**: сначала нужна диагностика, затем исправление.

## 2. Что значит «серый» — три разных случая
| Вид | Признак | Где в коде |
|---|---|---|
| A. Серое изображение | Эскиз есть, но кадр залит серым (полностью или нижняя часть) | `ThumbnailCacheManager.loadThumbnail`, fast-path префикса, кэш на диске |
| B. Серая плитка без картинки | `thumbnail == nil`, `isLoading == false`, иконка не видна | `FileGridCell.loadThumbnailAsync`, пропуск при throttle/ошибке |
| C. Вечный спиннер, затем серо | Запрос завис или отклонён очередью | `RemoteThumbnailQueue`, `transport.readChunk`, `fetchFile` |

Исполнитель обязан сначала определить, какой из случаев воспроизводится (скриншот + лог п. 4).

## 3. Гипотезы (проверять по порядку)
1. **Старый кэш/старый бандл.** Серые эскизы, записанные версиями ≤2.1.23 под ключом «путь»; при ключе `путь|размер|mtime` они не должны читаться — убедиться, что запущен бандл 2.1.24 (`CFBundleShortVersionString`) и что каталог `~/Library/Caches/com.macandroid.filemanager.thumbnails` очищен.
2. **Ошибки глотаются.** В `loadThumbnail` `try? await transport.readChunk` и `catch { return nil }` скрывают причину; `readChunk` использует interactive-канал и при недоступности канала возвращает ошибку. Нужно логировать каждую ветку.
3. **Throttle от трансфера.** `isThrottledDueToTransfer` остаётся `true` после зависшего/отменённого копирования → все удалённые эскизы пропускаются (случай B). Проверить сброс в `defer` и при отмене задачи.
4. **Файлы HEIC/HEIF/DNG/WebP.** Префикс 128 КБ не даёт эскиза → полная загрузка только до 15 МБ; для крупных файлов эскиза нет вовсе. Фото Xiaomi 14 Ultra часто 5–25 МБ.
5. **Частично скачанный файл в кэше QuickLook.** `isCached` проверяет только размер; `.part` не должен читаться, но проверить гонку параллельных `fetchFile`.
6. **Размер превью `targetSize`.** Передаётся `size*2`; при ползунке 256 → 512 px, EXIF-эскиз 160 px отбрасывается порогом `min(max,320)/2`, уходит в полную загрузку.
7. **Отмена задач SwiftUI.** `.task(id:)` отменяется при прокрутке; результат не применяется, а повторного запроса при возврате ячейки нет, если id не изменился.

## 4. Диагностика (первый этап, без изменения поведения)
- Добавить в `SSHTransportLog` записи: `THUMB_START path size`, `THUMB_CACHE_HIT`, `THUMB_SKIP reason=(throttle|size|noTransport|cancelled)`, `THUMB_PREFIX bytes=N exif=(yes|no)`, `THUMB_FULL_DL ok/err`, `THUMB_DECODE ok/nil w×h`, `THUMB_DONE ms`.
- Опционально: переключатель «Диагностика эскизов» в окне настроек пути/вида (или `defaults write … thumbDebug`).
- Воспроизвести на реальной папке `DCIM/Camera`, приложить `transport.log` и скриншот.

## 5. Требования к исправлению
1. Любой файл-изображение телефона ≤60 МБ получает **либо корректный эскиз, либо иконку типа** — никогда серый кадр и никогда «пустую» плитку.
2. Кэш не должен сохранять изображения, где основная область однородно серая (валидация: доля уникальных значений в нижней трети кадра; серый эскиз не пишется).
3. Пропуск из-за throttle обязан приводить к повторной попытке после его снятия (уже есть уведомление — проверить, что оно доходит до всех видимых ячеек).
4. Для HEIC/WebP/DNG без встроенного эскиза: фоновая загрузка до 25 МБ с приоритетом видимых ячеек, прогресс — спиннер, при ошибке — иконка и повтор по клику/обновлению панели.
5. Ошибки загрузки эскиза логируются; в UI — иконка типа файла, не серая плитка.
6. Кнопка/пункт меню «Сбросить кэш эскизов» (очистка памяти + диска) для проверки пользователем.

## 6. Критерии приёмки
- Папка из ≥100 фото телефона (JPEG и HEIC): после 30 с ожидания у всех видимых ячеек эскиз или иконка; серых плиток 0.
- Быстрая прокрутка вверх-вниз: видимые ячейки заполняются первыми, нагрузка ≤3 параллельных запросов.
- Копирование Phone→Mac во время просмотра: эскизы приостанавливаются, после завершения догружаются без перезахода в папку.
- Автотесты: серый кадр не кэшируется; HEIC-ветка; отмена; повтор после throttle. Все существующие наборы проходят.
- Версия поднята, `CHANGELOG.md`/`README.md` обновлены, бандл пересобран `./scripts/build_macos_app.sh`.

## 7. Вне объёма
