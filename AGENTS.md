# Инструкции и правила проекта MacDroid Commander

## Обязательное правило: Пересборка бандла приложения после изменений
После внесения любых изменений в исходный код Swift (`MacHost/Sources/...`) **ВСЕГДА ОБЯЗАТЕЛЬНО** пересобирать бандл приложения через:
```bash
./scripts/build_macos_app.sh
```

### Важное контекстное обоснование:
- Пользователь проверяет и валидирует изменения непосредственно в запущенном приложении `build/MacDroid Commander.app`.
- Одного прогона модульных CLI-тестов (`swift run MacHostTests`) недостаточно для проверки пользователем: без компиляции бандла в работающем у пользователя приложении изменения не вступают в силу.
- При завершении каждой задачи по коду MacHost необходимо гарантированно запускать сборку бандла `./scripts/build_macos_app.sh`.

## Обязательное правило: Ручная проверка запущенного приложения
После пересборки бандла агент **ВСЕГДА сам запускает** `build/MacDroid Commander.app` и проверяет изменение вручную, не полагаясь только на сборку и unit-тесты:
- Открыть приложение, воспроизвести сценарий, который меняется, и сверить результат с ожидаемым.
- Проверить и сам сценарий, и соседние места, которых правка может касаться.
- Перед кликами убедиться, что на переднем плане именно проверяемый экземпляр приложения (копий может быть запущено несколько, окна лежат друг на друге), и что пользователь в этот момент не работает в нём сам.
- Если проверить нельзя (нет доступа к интерфейсу, приложение не запускается) — прямо написать в отчёте, что именно не проверено и почему. Не писать «проверено», пока проверки не было.

Пользователю не передавать проверку ручного сценария: он проверяет результат, а не выполняет шаги за агента.

## Обязательное правило: Создание бэкапа перед и ПОСЛЕ ЛЮБЫХ изменений
Перед началом внесения любых изменений, правок, откатов или экспериментов с кодом, а также **ВСЕГДА ПОСЛЕ завершения любых изменений и сборки приложения** обязательно запускать:
```bash
./scripts/backup_project.sh
```
Скрипт создаёт полный изолированный снимок исходных кодов, состояния Git и готового бандла приложения в папку `.backups/`.
Строго запрещено выполнять `git checkout .`, `git reset --hard` или удалять файлы без предварительного запуска этого скрипта.
