# MacDroid Commander (Mac ↔ Android Dual-Pane File Manager)

Кроссплатформенный двухпанельный файловый менеджер в стиле **Total Commander** для macOS и Android (Xiaomi 14 Ultra / HyperOS).

## 1. Архитектура решения

Решение состоит из двух ключевых компонентов:
1. **MacHost (macOS 14+, Swift 6.2 / SwiftUI / AppKit):**
   - **Двухпанельный GUI:** Независимый выбор источников (`MacBook` локально, `Xiaomi 14 Ultra` по Wi-Fi/SFTP), табличное отображение, естественная сортировка, фильтрация и breadcrumbs.
   - **Колонка «Размер»:** моноширинный шрифт 12 pt; единицы размеров файлов и рассчитанных размеров папок — строчные латинские `b`, `kb`, `mb`, `gb` и далее. Числа форматируются с учётом языка системы.
   - **Приложения в Header:** системные иконки установленных Codex, Claude, Chrome, Telegram, WhatsApp, DeepL, Notion, Gemini, Visual Studio Code, «Заметок» и «Системных настроек» запускают приложения. Новые приложения добавляются справа от сохранённого ряда и также поддерживают перетаскивание. Кнопка обновления обеих панелей расположена непосредственно слева от «Aa» (групповое переименование). При перетаскивании синяя вертикальная полоска показывает место вставки перед или после иконки; порядок сохраняется между запусками.
   - **Ширина колонок:** «Размер», «Теги» и «Дата изменения» расширяются влево за левый разделитель, компенсируя ширину через «Имя». Остальные служебные колонки сохраняют ширину; «Тип» закреплён справа. Зона захвата разделителя — 14 pt, при наведении он подсвечивается. При достижении предела разделитель останавливается. Клик по заголовку сохраняет сортировку.
   - **Контекстное меню файлов:** одинаковый набор действий в таблице и сетке; можно создать папку с выбранными объектами, открыть файл через другое приложение, копировать, дублировать, архивировать, переименовывать и управлять показом скрытых файлов.
   - **Горячие клавиши Total Commander:** `Tab` (переключение панелей), `Пробел / F3` (Quick Look и просмотрщик HEIC), `F5` (Копирование), `F6` (Перемещение), `F7` (Создание папки), `F8` (Удаление), `Cmd+U` (Обмен панелей местами).
   - **Транзакционный журнал IntentLedger (SQLite WAL):** Полная регистрация всех операций до отправки команд в сеть.
   - **Двухфазный перенос (Two-Phase Commit):** Передача во временный файл `.<filename>.part.<actionId>`, расчет хэшей, атомарный коммит и только затем подтвержденное удаление оригинала при перемещении (Move).
   - **Нормализация Unicode (NFC):** Автоматическое приведение имен файлов из формата macOS (NFD) в канонический формат Android/Linux (NFC) для предотвращения рассинхронизации кириллицы.
   - **Транспорт:** mDNS Bonjour поиск сервиса `_macphone_sftp._tcp` с резервным ручным подключением по `IP:порт`. Кнопка PHONE запускает самостоятельный Wi-Fi-поиск без ввода IP: актуальные Bonjour endpoints и сохранённые IP:порт, затем ARP и скан локальной /24 подсети по порту 2222. До 6 секунд поиск принимает новые ответы Bonjour и повторяет временно недоступные адреса; отдельные сетевые пробы могут завершиться позже этого окна. Телефон опознаётся по закреплённому ключу узла, приоритет имеет последнее успешно подключённое устройство. Несопряжённый телефон требует однократного подтверждения отпечатка.
   - **Версия 2.1.229 (Android 2.1.15):** исправлены раннее завершение поиска PHONE, потеря порта, гонки Bonjour/ручного Connect и блокировка фонового подключения неподходящим кандидатом. Android перепривязывает сервер при смене Wi-Fi IP, в том числе когда основной маршрут занят VPN. [Детальное ревью](docs/WIFI_PEER_REVIEW_2026-10-22.md).
   - **Устойчивость Wi‑Fi:** кратковременный пропуск сетевой проверки не разрывает SFTP-сессию; последний рабочий адрес сохраняется для восстановления подключения.
   - **Версия 2.1.224 (Android 2.1.12):** исправления peer-review: сопряжение с явной сверкой SHA256-отпечатка ключа телефона (отпечаток виден на телефоне и в окне Mac), пины ключей по устройству, а не по IP; журнал передач по цели, защита от перезаписи при переименовании/перемещении, рабочий диалог конфликтов имён (по умолчанию «пропустить»), атомарная замена архива, backoff переподключений. Подробности в CHANGELOG.
   - **Версия 2.1.25:** устранение серых эскизов телефона: безопасное декодирование EXIF из `thumbJPEG`, детектор битых серых кадров `isCorruptedGrayFrame`, поддержка RAW DNG Xiaomi 14 Ultra, фоновая загрузка до 25 МБ, кнопка сброса кэша и устранение залипания плиток при прокрутке.
   - **Версия 2.1.24:** быстрые эскизы телефона: EXIF-эскиз из префикса файла, LIFO-очередь с отменой, догрузка после трансфера, кэш с учётом mtime.
   - **Версия 2.1.23:** после перехода вверх или «Назад» курсор возвращается на папку, из которой вышли; стрелки в Quick Look листают файлы в порядке сортировки панели.
   - **Версия 2.1.22:** кнопки навигации используют стрелки нового дизайна, разделительные линии утолщены до 1,5 pt.
   - **Версия 2.1.18:** кнопки навигации вверх, назад и вперёд разделены вертикальными линиями; иконка режима просмотра увеличена на 23%.
   - **Версия 2.1.17:** надпись Phone Offline и предупреждение перемещены перед кнопкой Connect в правую часть строки; размер подписи — 12 pt.
   - **Версия 2.1.16:** в окне сопряжения увеличен заголовок списка устройств и скрыт отпечаток хост-ключа.
   - **Версия 2.1.15:** история подключений показывается перед mDNS-устройствами; список mDNS содержит до 10 IPv4 адресов. Офлайн-панель показывает Phone Offline и одну кнопку Connect.
   - **Версия 2.1.14:** подписи дисков Mac, Phone и USB используют шрифт и размер названий папок в пути.
   - **Версия 2.1.13:** Ctrl+C/A/V/X работают в текстовых полях, включая переименование; путь можно редактировать кликом по полосе над крошками, а его контекстное меню копирует и вставляет путь.
   - **Версия 2.1.12:** контекстное меню файлов унифицировано для таблицы и сетки; добавлено создание папки с перемещением в неё выбранных объектов.
   - **Версия 2.1.11:** окно соединения начинает с последнего успешного IP; история ограничена четырьмя последними адресами. IPv6 scope отображается один раз (`fe80::…%en0`), а повторный поиск проверяет последний адрес до истории и новых Bonjour-адресов.
   - **Версия 2.1.10:** SSH `UserKnownHostsFile` корректно передаётся OpenSSH, включая путь с пробелом в `Application Support`; host-key alias и запись `known_hosts` согласованы с OpenSSH. ControlMaster использует короткий путь сокета для ограничения macOS. Переподключения сохраняют политику ключей, простаивающий SFTP-канал проверяется запросом `stat`, а ошибки SSH содержат код завершения и дочитанный stderr. Сброс host key очищает соответствующую запись. Подробная диагностика записывается в `~/Library/Logs/MacDroidCommander/transport.log`. Первичное сопряжение по USB и Wi-Fi требует одноразового 60-секундного окна на телефоне.
   - **Версия 2.1.5:** USB-сессия привязана к serial устройства и актуальному ADB-forward порту; автоподключение работает с выбранным доверенным serial. Подпроцессы ADB и сетевые проверки имеют конечные таймауты, монитор проверяет активный endpoint, а окно сопряжения показывает диагностический журнал. Bonjour-резолвинг дедуплицирует повторные события.
   - **Проверка транспорта без телефона:** `cd MacHost && swift run TransportRegressionTests` проверяет таймауты и отмену на локальном процессе, имитирующем неотвечающий сервер. Эти проверки не заменяют проверку Wi‑Fi с телефоном.
   - **Кэш миниатюр:** Двухуровневый кэш (RAM + Дисковый LRU до 500 МБ) и полноэкранная галерея с нативным декодированием HEIC/DNG и предзагрузкой $\pm 2$ соседних фото.

2. **AndroidCompanion (Android 14+, Kotlin / Apache MINA SSHD / Room):**
   - **Фоновый демон:** `FileDaemonService` (тип `dataSync`) с удержанием `PARTIAL_WAKE_LOCK` во время передачи данных.
   - **Встроенный SFTP/SSH-сервер:** Apache MINA SSHD на порту 2222 с генерацией постоянных ключей хоста Ed25519.
   - **Хуки коммита SFTP:** `CustomSftpEventListener` перехватывает переименования `.part` в целевой файл и фиксирует квитанции в Room БД `ActionJournalDb`.
   - **Синхронизация с системной галереей:** Вызов `MediaScannerConnection.scanFile()` сразу после завершения коммита.
   - **Сетевое анонсирование:** Публикация сервиса через Android `NsdManager`.
   - **Онбординг прав:** Запрос системного разрешения `MANAGE_EXTERNAL_STORAGE` (All Files Access) и рекомендации по настройке автозапуска и батареи HyperOS ("Нет ограничений").

## Корзина телефона

Обычное удаление (`F8`, `Delete`, `Cmd+Delete`) перемещает выбранные объекты в собственную корзину MacDroid — скрытую папку `.MacDroidTrash` в корне того же накопителя телефона. Это сохраняет файлы и вложенные папки без копирования на Mac. Если перемещение недоступно, операция завершается ошибкой; автоматического безвозвратного удаления нет.

Откройте корзину кнопкой с иконкой корзины в правом нижнем углу окна или через «Корзина телефона…» в меню файлов. Для телефона с несколькими накопителями показывается корзина накопителя текущей панели телефона. Можно восстановить объект в исходное место или очистить показанную корзину после отдельного подтверждения. Восстановление не перезаписывает существующие файлы; исходная родительская папка должна существовать. Корзина сохраняется на телефоне между перезапусками MacDroid и занимает место до очистки. Не удаляйте и не редактируйте её служебные записи вручную.

## Освободить место — copy done

После успешного копирования с телефона на Mac появляется предложение проверить копии. Команда «Освободить место — copy done» также доступна в контекстном меню файлов, папок и свободного места панели телефона, в таблице и сетке; в меню пути — для текущей папки. Для папок учитываются вложенные импорты. Область поиска ограничена местами, записанными в истории импорта этого телефона: приложение не сканирует весь Mac. Если копию перенесли в неизвестное приложению место, она не будет найдена.

История передачи не подтверждает наличие копии. При каждой проверке заново читаются файлы телефона и Mac, сравнивается SHA-256 полного содержимого. Отсутствующие, недоступные, изменённые копии и символические ссылки не считаются подтверждёнными. В окне показаны конкретные файлы телефона, размеры и пути всех найденных копий Mac с кнопкой показа в Finder. Файл телефона учитывается один раз, даже если копий несколько. Выбор файлов выполняется вручную.

Перед переносом повторно проверяются файл телефона и хотя бы одна из показанных копий Mac. Файлы перемещаются исключительно в корзину приложения на телефоне. После переноса дополнительно проверяется содержимое перенесённого файла и копия Mac; при изменении выполняется восстановление. Ошибка или смена подключения останавливает операцию и показывает число подтверждённых переносов. Если восстановление недоступно, файл сохраняется в корзине и показывается путь для восстановления. Повторное действие требует новой проверки.

Показанный объём освободится только после отдельной очистки корзины телефона. До очистки файлы можно восстановить через «Корзина телефона…». Проверка SHA-256 передаёт полное содержимое телефона по SFTP и может занять значительное время; её можно остановить.

## Поиск и фильтр в верхней панели

Кнопка поиска или Cmd+F открывает поле и выбор поиска по имени/содержимому во всплывающем окне под иконкой. Фильтр открывается аналогично. Кнопки верхней панели сохраняют свои позиции при раскрытии полей. Щелчок вне окна закрывает его, сохраняя введённый запрос; повторное открытие позволяет продолжить ввод. Esc очищает запрос и закрывает окно.

## Поиск точных дубликатов

«Файл» → «Найти точные дубликаты…» (также доступно в меню «Действия») открывает поиск в двух текущих папках Mac/Phone и их подпапках. Файлы группируются по размеру, затем по SHA-256 всего содержимого; имена и даты могут отличаться. Символические ссылки на файлы и папки пропускаются, включая ссылки внутри пакетов приложений; обычные файлы внутри пакетов проверяются. Повторяющиеся корни не создают повторных записей, собственная корзина телефона исключается из поиска.

Можно вручную отметить копии или нажать «Отметить лишние, оставить одну копию». Перемещение в корзину требует отдельного подтверждения; в каждой группе должна остаться хотя бы одна копия. Перед перемещением содержимое отмеченных файлов и оставляемой копии проверяется повторно. При ошибке поиск/очистка останавливается с сообщением, без выдачи неполного поиска за полный результат. Хэширование телефона передаёт содержимое по SFTP и может занимать время.

## Просмотр ZIP/APK

Двойной клик по ZIP/APK открывает просмотр архива с папками, переходом вверх и поиском. Файлы внутри архива работают как в обычной папке: один клик выделяет объект, двойной клик или Enter открывает файл в программе по умолчанию либо переходит в папку; пробел открывает/закрывает системный Quick Look. Стрелки в Quick Look переключают файлы текущей папки архива, Esc закрывает просмотр. Отдельных кнопок просмотра и открытия нет; команды «Открыть», «Быстрый просмотр» и «Извлечь…» доступны в контекстном меню. Только выбранный файл читается во временную изолированную папку. Копия доступна только для чтения: для Quick Look удаляется при закрытии просмотра, для внешней программы хранится до завершения MacDroid, чтобы файл оставался доступен после закрытия окна архива. Архив не изменяется, выбор папки для извлечения не требуется. Команда «Извлечь…» отдельно сохраняет файл на Mac. Остальные элементы не распаковываются. Файл извлекается в выбранную папку на Mac без перезаписи существующего файла. Для архива на телефоне сначала загружается временная копия сжатого архива на Mac; она удаляется при закрытии просмотра.

Поддерживается до 100 000 записей, 1 ГиБ на элемент и 4 ГиБ суммарного распакованного размера. Зашифрованные, многотомные архивы, ссылки, небезопасные пути и повторяющиеся пути отклоняются с сообщением. Для полной распаковки выберите «Разархивировать» в контекстном меню архива (над «Сжать в архив…») либо «Распаковать выбранный архив полностью» в меню файлов. Контекстная команда доступна в таблице и сетке; для обычных файлов и папок она неактивна.

## Сравнение папок

«Сравнить папки» рекурсивно проверяет содержимое одноимённых папок на Mac и телефоне, включая скрытые файлы. Отличие любого вложенного элемента отмечает родительскую папку как изменённую. Для файлов одинакового размера сравниваются потоковые SHA-256 всего содержимого, независимо от даты изменения. Совпадение размера и времени само по себе больше не считается равенством. Ошибка чтения или изменение файла во время проверки прерывают сравнение. Пока идёт обход, строка состояния показывает проверку содержимого. Повторное нажатие отключает сравнение; переход в другую папку отменяет прежний обход и запускает новый после загрузки панелей. Ошибка чтения, цикл ссылок или глубина более 256 уровней прерывают сравнение с сообщением, без выдачи непроверенных папок за одинаковые.

## 2. Быстрый запуск на macOS

### Сборка и запуск тестов верификации:
```bash
cd MacHost
swift run MacHostTests
swift run PhoneTrashTests
swift run ContentToolsTests
swift run ArchiveInteractionTests
```

### Запуск графического приложения:
Из корня проекта откройте готовый бандл:
```bash
open "build/MacDroid Commander.app"
```

Для первой сборки используется `./scripts/build_macos_app.sh`. После пересборки штатно завершите старый экземпляр, затем откройте бандл: обычный `open` активирует уже запущенный процесс, даже если на диске его бандл обновлён. Не используйте `open -n` для обычного запуска и не запускайте `swift run MacHost` поверх работающего бандла — это создаёт отдельные процессы. Версия в интерфейсе должна совпадать с версией собранного приложения.

## 3. Сборка Android-компаньона

1. Откройте папку `AndroidCompanion` в **Android Studio**.
2. Подключите телефон (Xiaomi 14 Ultra) по USB или Wi-Fi adb.
3. Нажмите кнопку **Run (▶)** или выполните в консоли:
```bash
cd AndroidCompanion
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/MacDroidCompanion-*.apk
```
4. При первом запуске на смартфоне подтвердите диалог **«Доступ ко всем файлам»** (`MANAGE_EXTERNAL_STORAGE`).
5. В настройках HyperOS для приложения включите **«Автозапуск»** и установите **«Контроль активности» -> «Нет ограничений»**.

Архив будет сохранен как `mac_android_filemanager_v2.zip`.

### Рабочие копии файлов телефона

Открытие файла телефона во внешней программе (включая «Открыть с помощью») создаёт постоянную рабочую копию на Mac. Повторное открытие того же пути на том же телефоне использует эту копию и сохраняет правки редактора. Кнопка **«Рабочие копии»** на верхней панели открывает список; изменения проверяются по SHA-256 при возврате в приложение, открытии списка и по команде «Проверить изменения».

Сохраните файл в редакторе, затем нажмите **«Сохранить на телефон как копию»**. Приложение отправит отдельный снимок в исходную папку под именем `имя.edited-<UUID>.расширение` и проверит SHA-256. Оригинал телефона сохраняется. Новые правки редактора во время передачи останутся отмеченными как изменения. Требуется подключение к тому же телефону с закреплённым SSH-ключом; другой телефон не принимается.

Сессии и локальные снимки хранятся в `~/Library/Application Support/MacDroidCommander/ExternalEdits/` и восстанавливаются после перезапуска. Автоматической очистки пока нет. При ошибке связи результат отправки может быть неизвестен: список показывает путь неподтверждённой попытки, локальная версия сохраняется, а повторная отправка использует новое имя. Незавершённые скрытые `.mcdedit-*.part` на телефоне также сохраняются для разбора. Сохранение заменой исходного файла и постоянное фоновое наблюдение запланированы отдельно: [план реализации](docs/managed_phone_editing_plan.md).
